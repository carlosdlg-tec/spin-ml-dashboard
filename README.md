# Evidence 3 – Machine Learning Dashboard (Spin by OXXO)

Everything needed to run `Evidence_3_Machine_Learning_Dashboard.ipynb`, locally or in Google Colab.

```
Evidence_3_Machine_Learning_Dashboard/
├── Evidence_3_Machine_Learning_Dashboard.ipynb   notebook (runs locally or in Colab)
├── Dataset_clean.csv                              monthly user dataset (50,000 users, Jan 2025 – Jul 2026)
├── Evidence 3/
│   ├── g3_clustering_features.csv                 loaded in "Purchase Persona"
│   ├── g3_propensity_model_dataset.csv            loaded in "Propensity Model"
│   └── dashboard_inputs/                          persona + Flip-Out model outputs used by the dashboard
│       ├── persona_labels.csv
│       ├── scores_T2.csv
│       ├── F10_shap_mean_abs.csv
│       ├── LR_coefficients.csv
│       ├── T7_best_configs.csv
│       └── logos/                                 Spin, OXXO, Walmart, H-E-B and La Comer logos (copied to spin_dashboard/assets)
├── spin_dashboard/                                generated by the notebook: app.py, data/, assets/, .streamlit/
├── run_dashboard.bat                              opens the already-built dashboard
└── requirements.txt
```

## Option A – just open the dashboard (Windows)
Double-click `run_dashboard.bat`, then go to http://localhost:8501.

## Option B – run the notebook locally
```
pip install -r requirements.txt
jupyter notebook Evidence_3_Machine_Learning_Dashboard.ipynb
```
Run all cells from this folder. The notebook rebuilds `spin_dashboard/` and launches the dashboard at http://localhost:8501 (also shown inside the notebook).

## Option C – Google Colab
Upload the contents of this folder to `MyDrive/SPIN_G3/` in Google Drive (so the paths are
`MyDrive/SPIN_G3/Dataset_clean.csv` and `MyDrive/SPIN_G3/Evidence 3/...`), open the notebook in Colab and run all cells.
The last cell can create a temporary public link (Cloudflare tunnel) – Colab only.

## Option D – Streamlit Community Cloud
Deployed from this repo with main file `spin_dashboard/app.py`. Cloud installs `spin_dashboard/requirements.txt`
and reads the theme from the root `.streamlit/config.toml` (keep it in sync with `spin_dashboard/.streamlit/config.toml`).
Every push to `main` redeploys the app.

## Data not in the GitHub repo
`Dataset_clean.csv` (146 MB) and `Evidence 3/g3_propensity_model_dataset.csv` (337 MB) are over GitHub's 100 MB
file limit, so they are git-ignored. Copy them into the paths shown above before running the notebook.
The dashboard itself (Option A) does not need them: `spin_dashboard/` already contains its data.

Note: `Dataset_clean.csv` is a copy of the `part-00000-...csv` monthly file (same rows and columns the notebook expects).
